# Cookbook — things to ask, in plain English

These are full-flow examples — short transcripts a real shop owner could read top-to-bottom and follow. Each one chains a few skills together to solve a recurring problem.

## Stories

- **[First-time setup](first-run.md)** — what happens the first time you connect a store.
- **[Monday morning](monday-morning.md)** — the standard end-of-week pulse.
- **[Catalog cleanup day](catalog-cleanup-day.md)** — quarterly housekeeping for your products.
- **[Receiving a shipment](post-shipment-intake.md)** — PO arrived; here's the flow.
- **[Launching a sale](pre-sale-launch.md)** — picking what to discount, scoping it safely.
- **[Win-back cycle](win-back-cycle.md)** — building a re-engagement list (note: actually sending it needs another tool).

Every example uses placeholder data. Your real run will show your actual store.
