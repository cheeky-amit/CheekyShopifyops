# Top customers by spend

Ranked list of top spenders or repeat buyers.

> "Top customers."
> "Best 20 spenders."
> "Repeat buyers in Canada."

## What it returns

A ranked list with first name + last initial, lifetime spend, order count, and country. Names are abbreviated for privacy in this view; ask for one specific customer to see full details.

## What this skill won't do

- Send emails to these customers (no email MCP in this bundle — see `meta.wiring`).
- Tag/un-tag customers in bulk (would need GraphQL mutation; defer to a future skill).
