# Find orders

Plain-language order search.

> "Find orders from this week."
> "Orders over $200."
> "ORDER-1001"
> "Orders for customer@example.com"

## What it returns

A compact list of matching orders, or — if there's only one match — the full order detail.

Customer names abbreviated to first name + last initial in list view.

## What this skill won't do

- Refund or cancel orders. Refunds are blocked at the MCP level; do those in Shopify admin.
- Fulfill or ship orders. No direct tool exposed for this v1.
