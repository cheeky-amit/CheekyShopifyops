# Shop snapshot

A one-glance "where am I" — shop profile plus a few high-level counts.

> "Shop snapshot."
> "What plan am I on?"
> "Show me my store."

## What it returns

- Domain, plan, currency, timezone, country.
- Product count, collection count.
- Orders and sales for the last 7 days.

Useful as the first thing to ask after `switch-shop` or at the start of a session.
