# Where do sales come from

Channel mix — sessions, orders, sales, and conversion by referrer source (and optionally by named referrer like Instagram vs Facebook).

> "Where do sales come from?"
> "Traffic sources last 30 days."
> "What's driving sales?"

## Drill-in

`dimension: source-and-name` splits by both source and named referrer (Instagram, Google, Facebook, etc.).

## "Direct" caveat

A large share of "direct" traffic is actually unattributable (deep links, dark social, browser-cleared referrers). The skill surfaces this so the number isn't taken at face value.
