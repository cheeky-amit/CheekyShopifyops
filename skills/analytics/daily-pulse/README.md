# Daily sales pulse over a date range

Trend view of sales, orders, AOV, sessions, conversion — for any range — with auto-comparison to the previous period.

> "Sales last 30 days."
> "Weekly sales."
> "Sales for 2026-01-01..2026-01-15."

## Ranges

`today`, `yesterday`, `last-7d`, `last-30d`, `last-90d`, `mtd`, `qtd`, `ytd`, or a custom `<SINCE>..<UNTIL>` (ISO dates).

## Plan-tier note

Session and conversion metrics require Shopify plan or higher. On Basic, the skill falls back to sales-only metrics and tells you so.
