# Session-to-purchase funnel

Five-stage funnel with drop-off at each step.

> "Conversion funnel."
> "Where are people dropping off?"
> "Checkout funnel last 30 days."

## What it returns

```
Sessions
  → cart add            (step rate 1)
  → reached checkout    (step rate 2)
  → completed checkout  (step rate 3)
```

Plus the overall conversion rate and a one-line interpretation.

## Optional split

By device type, country, or referrer source — surfaces where the funnel breaks worst.
