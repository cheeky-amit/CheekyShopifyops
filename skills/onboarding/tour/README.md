# tour

A short read-only walkthrough of what Claude can do on your store. Skim it once, then go ask for whatever you need.

## When this runs

- On request: "what can you do?", "show me around", "tour", "list your skills", "what skills are available".

## What you'll see

Nine short blocks, one per category, each with a one-line description and 2–3 sample asks you can copy-paste:

- **catalog** — products, statuses, content checks, duplicates.
- **inventory** — stock levels, low-stock alerts, cycle counts, receiving.
- **orders** — read-only views of orders.
- **customers** — VIPs, top spenders, marketing consent.
- **promotions** — create and audit discount codes.
- **analytics** — sales, top sellers, referrers, funnel, cohorts.
- **retention** — win-back and anniversary lists.
- **storefront** — shop snapshot, new-store previews.
- **reporting** — weekly brief.

It ends with one of:
- "Want to set up properly? Say 'set me up'." — if you haven't onboarded yet.
- "You skipped onboarding earlier — that's fine. Say 'set me up' any time." — if you skipped.
- "All set up. What do you want to work on?" — if you already onboarded.

## What this never does

- Writes anything.
- Reads more than your shop's basic profile (name, plan, currency, timezone) and onboarding state.
- Confirms anything — there's nothing to confirm.
